# Linux Networking

Мережа дозволяє комп'ютерам обмінюватися даними.

Основні поняття:

IP-адреса — адреса пристрою в мережі.
MAC-адреса — фізична адреса мережевого інтерфейсу.
Порт — точка, через яку працює мережевий сервіс.
Протокол — правила обміну даними.

Основні команди Linux:

ip addr
ip route
ping
ss
hostname
curl

## Практика

Перегляд мережевих інтерфейсів:
ip addr

Перегляд маршрутів:
ip route

Перегляд відкритих портів:
ss -tuln

Перевірка мережевого з'єднання:
ping -c 4 1.1.1.1
